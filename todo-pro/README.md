# To-Do App (Pro) — TaskCraft

**Author:** Divya Sabale

This is a slightly advanced front-end To-Do application built with HTML, CSS, and JavaScript. It is a local demo (no backend) and stores data in the browser using `localStorage`.

## Features
- Add tasks with title, due date, notes, and priority (High/Medium/Low).
- Mark tasks complete, edit, and delete tasks.
- Filter by status (All/Active/Completed) and by priority.
- Search tasks and sort by due date (ascending/descending).
- Export tasks to JSON and import from JSON.
- Responsive layout with modern UI.

## How to use
1. Unzip the folder.  
2. Open `index.html` in any modern browser (Chrome recommended).  
3. Add a task on the left. Use filters to view tasks. Export/import via buttons.

## Why this approach
This demo shows practical front-end skills (DOM manipulation, state management, UI/UX). It is intentionally client-side to be easy to run and present in interviews.
